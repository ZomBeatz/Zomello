Set up Zomello

To install Zomello as an app, this device needs to trust your computer's secure connection. You only do this once.

Checking the secure connection…

All set. Open Zomello, then install it:

Chrome: ⋮ menu → Install app.

Open Zomello

Android

  1. Download certificate
  2. Open your phone's Settings and search for “CA certificate”. (Usually: Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate.)
  3. Tap Install anyway, then choose zomello-ca.crt from Downloads.
  4. Come back to this page. It notices by itself and shows Open Zomello.

iPad / iPhone

  1. Download certificate and tap Allow.
  2. Settings → General → VPN & Device Management → Zomello → Install.
  3. Settings → General → About → Certificate Trust Settings → turn on Zomello.
  4. Come back here and tap Open Zomello, then Share → Add to Home Screen.

On iPad and iPhone this step is optional: Add to Home Screen also works without it.

Why is this needed? Is it safe?

Browsers only let you install web apps from secure (https) addresses. Your computer can't get a public certificate for a home-network address, so Zomello made its own, just for this computer.

It is limited to home-network addresses, so it can't be used to vouch for any real website. You can remove it any time from the same Settings screen.

Continue without installing

Use Zomello in the browser instead (no app install).
