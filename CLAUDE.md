# Zomello

Zomello is a ZomBeatz Media app: a planner with boards, buckets and cards (Tauri 2 + React + TypeScript; Rust server in `server/`).

- **Design and wording:** follow the ZomBeatz design system: https://github.com/ZomBeatz/zombeatz-docs/blob/main/design/DESIGN.md (colors, type and spacing in `design/tokens.css` there; locally `../zombeatz-docs/design/` if it's checked out next to this folder). Zomello's own `src/styles.css` uses the same values.
- **Guide pages** for Zomello live in the zombeatz-docs repository under `site/zomello/`. When a feature changes here, update its page there.
- **Never commit** signing keys, `keystore.properties`, passwords or personal email addresses. The contact address is info@zombeatzmedia.com.
